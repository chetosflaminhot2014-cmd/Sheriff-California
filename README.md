# Sheriff Department — California Roleplay

Portal estático ficticio para el universo de California Roleplay. No representa a una agencia gubernamental real.

## Archivos
- `index.html`: estructura y contenido del sitio.
- `style.css`: estilos adaptables para móvil y escritorio.
- `script.js`: menú móvil y año automático.

## Publicar en Render
1. Entra a https://dashboard.render.com/ y pulsa **New +**.
2. Selecciona **Static Site**.
3. Conecta el repositorio `chetosflaminhot2014-cmd/Sheriff-California`.
4. Usa la rama `main`.
5. Deja **Build Command** vacío.
6. En **Publish Directory**, escribe `.`
7. Pulsa **Create Static Site**.

Render publicará el sitio y podrá desplegar automáticamente futuros cambios enviados a la rama `main`.

## Personalización
Las fechas de convocatorias y enlaces de inscripción deben actualizarse cuando estén definidos oficialmente dentro del servidor de roleplay.
